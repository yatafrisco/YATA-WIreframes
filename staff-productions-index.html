Parent accepts BEFORE processing time Applies today
  1. Existing future-payment authorization workflow.
  2. Parent selects a payment method and authorizes the scheduled charge.
  3. If authorized in time, the charge processes at the scheduled processing time.
  4. If authorization is still outstanding when that time passes, the existing charge moves to the existing Due Now workflow, including the Parent Portal “Action Needed” section.
Parent accepts AFTER processing time
  1. Existing Due Now checkout workflow.
  2. Immediate payment is required to finalize Role Acceptance.
  3. Existing payment statuses, retry and recovery behavior apply.
